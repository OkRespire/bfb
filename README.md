# BFB (Boring File Browser)

A simple TUI file browser built with ratatui. WIP. This is mostly a learning project, so expect bugs.

## Keybinds
- k/up -> move up
- j/down -> move down
- . -> toggle hidden files
- ENTER/l/right -> open
- BACKSPACE/h/left -> go to parent directory
- ESC/q/Ctrl+C -> Close

## Features
- Directory Traversal
- Open Files using `xdg-open` or using the `$EDITOR` envar after inspecting the file
  - If `$EDITOR` is not set, it will fallback to `vi`

## Building
To build you can do

```bash
cargo build
```
or if you are using Nix
```bash
nix build
```

## Running
To run you can do
```bash
cargo run
```
or if you are using Nix
```bash
nix run
```
